# LEGO Education Resources

This repository collects LEGO Education lesson indexes, example programs, and related materials for several product lines. It is organized as a reference hub for educators, students, and hobbyists who want to explore official lessons and build ideas across different LEGO Education sets.

## What this repository contains

- Official lesson indexes for LEGO Education products:
  - SPIKE Prime
  - SPIKE Essential
  - BricQ Motion Prime
  - BricQ Motion Essential
  - Simple & Powered Machines (Set 9686)
- Example Python programs for SPIKE Prime lessons in the CS2N curriculum.
- Public project collections and build walkthrough references for SPIKE Prime.

## Highlights

- Curriculum-oriented lesson catalogs for elementary and middle school learners
- Hands-on STEM, robotics, engineering, and coding activities
- Sample code for programming SPIKE Prime robots
- Community project ideas that complement the official lessons

## How to use this repository

1. Browse the product-specific folder that matches your LEGO Education set.
2. Open the lesson index for curriculum planning or classroom reference.
3. Explore the SPIKE Prime example programs for coding practice and inspiration.

This repository is intended as an educational resource and reference collection for LEGO Education learning materials.
